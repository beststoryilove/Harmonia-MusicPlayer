API 令牌
大部分服务商使用 Bearer Token 认证。密钥仅保存在本机浏览器，存在被本机恶意程序读取的风险，请勿使用高权限密钥。
API 端点预设
API Base URL
支持 OpenAI 兼容格式 (如 DeepSeek、通义千问、Moonshot 等)，大部分服务商使用 /v1/chat/completions 路径
模型名称
输入要使用的模型名称。切换端点时会自动填充默认值，也可修改为任意模型
思考模式
开启后 AI 会先思考再翻译，质量更高但响应更慢
自动重试
翻译结果不完整时自动重试（最多 2 次）

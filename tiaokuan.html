隐私政策

Harmonia 音乐播放器（以下简称“本项目”）非常重视您的隐私。本隐私政策旨在透明地说明我们如何处理信息。

1. 本地存储数据

本项目不会收集或上传任何个人信息。所有用户数据仅存储在您设备的浏览器本地（通过 localStorage），包括：

  • 您的播放列表、收藏歌曲、播放历史；
  • 播放设置（音量、播放模式、主题偏好）；
  • 歌词翻译设置及您自行填入的 API 令牌（仅存本地，用于请求翻译服务）；
  • 自定义歌单排序（拖拽顺序）。

上述数据由您完全控制，清除浏览器缓存或使用隐私模式将导致数据丢失。本项目无法访问、存储或共享这些数据。

2. 第三方接口调用

为提供音乐、歌词、专辑封面等功能，本项目会向以下第三方服务发起请求：

  • 音乐元数据接口（如 music-api.gdstudio.xyz、网易云音乐API）
  • 歌词翻译接口（智谱 GLM-4-Flashx —— 需您自行提供API密钥）
  • CORS代理（仅用于解决逐字歌词跨域问题，由开发者提供）

所有请求均由您的浏览器直接发起，本项目本身无后端服务器，不代理、不中转、不记录您的任何请求内容。第三方服务的数据收集行为请参阅其自身隐私政策。

3. 桌面歌词功能

若您使用“桌面歌词”功能，本项目将通过 WebSocket 连接您本地运行的歌词客户端（如 HarmoniaLyrics.exe）。通信仅限于发送当前歌曲信息、歌词文本及播放进度，不传输任何身份信息。此连接仅在本地进行，不经过互联网。

4. 个人隐私

本项目不会收集您的个人信息（包括但不限于：您访问本项目的IP地址、您当前所在国家、您的设备信息、您的系统信息等）。
（*“本项目”仅指Harmonia音乐播放器，不包括API提供商、项目托管平台。）
